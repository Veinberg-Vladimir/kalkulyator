## Как обновить
1. Правишь `index.html` (или просишь Claude)
2. В этой папке: `git add -A && git commit -m "что поменял" && git push`
3. Через минуту страница обновлена. Проверка: открыть адрес, в кэше телефона может держаться старая версия, обновить страницу

## Что внутри (образец: vrtoapp.com/tdee-calculator Марка)
- Шапка: градиент серый-хаки, заголовок «Бесплатный калькулятор калорий», справа фото Владимира (`img/hero.png`, его собственный обрез по пояс, прозрачность вычищена). Три яруса: телефон 232 px, планшет 300, ноутбук 400. Низ фото = низ шапки, карточка формы ниже, без наезда
- Поля: пол (только переключает ориентир по жиру), вес, % жира, активность (5 уровней: 1,2 / 1,375 / 1,55 / 1,725 / 1,9), «давно сидишь на диете?» (да = минус 100 ккал)
- Ориентир по % жира: кнопка «Не знаешь свой процент? Посмотри ориентир» → 6 строк на пол со схематичными фигурами (`img/men-1..6.png`, `img/women-1..6.png`, нарисованы через Codex, исходные полосы в `img/_gen/`). Нажатие на строку подставляет процент. Живые фото Владимир отверг
- Формула Кэтча-Макардла: сухая масса = вес × (100 − жир) / 100; базовый обмен = 370 + 21,6 × сухая масса; поддержка (TDEE) = базовый обмен × активность − (100, если диета). Белок = 2 г × вес. Зоны: сушка = TDEE × 0,8; поддержание; набор = TDEE × 1,1
- Проверка на примере Марка: 95 кг, 28%, активность 1,55 → 2 864 ккал, белок 190 г, зоны 2 291 / 2 864 / 3 150
- Результат заменяет форму (как у Марка), кнопка «← Пересчитать». Блок «Как это работает»: три карточки, перевод текстов Марка
- Без брендинга, подвала и приписок: так решил Владимир 03.10

## Сбор почты (лид-магнит), ВЫКЛЮЧЕН
В `index.html` в начале скрипта есть `var LEAD={endpoint:'', name:'', email:'', data:''}`. Пока `endpoint` пустой, результат показывается сразу. Как включить:
1. Владимир создаёт Google Форму с тремя вопросами «краткий ответ»: Имя, Почта, Расчёт, и присылает ссылку
2. Из ссылки формы берём адрес `.../formResponse` и идентификаторы полей `entry.NNNN` (видны в исходнике страницы формы или в ссылке «предзаполненный ответ»)
3. Вписываем: `endpoint:'https://docs.google.com/forms/d/e/<id>/formResponse', name:'entry.…', email:'entry.…', data:'entry.…'`, пушим
После этого цифры результата размыты до ввода имени и почты, заявка уходит в таблицу формы строкой: пол, вес, %, активность, диета, TDEE, белок

## Свой домен, НЕ КУПЛЕН
Когда будет домен: в настройках репозитория Pages → Custom domain вписать домен, у регистратора 4 A-записи на 185.199.108.153 / 109.153 / 110.153 / 111.153 и CNAME www → veinberg-vladimir.github.io. Проверка и включение HTTPS занимают до часа
